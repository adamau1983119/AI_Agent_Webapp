# Influencers AI - Frontend

## 🚀 快速開始

### 安裝依賴

```bash
npm install
```

### 啟動開發伺服器

```bash
npm run dev
```

瀏覽器會自動打開 `http://localhost:3000`

### 建置生產版本

```bash
npm run build
```

### 預覽生產版本

```bash
npm run preview
```

---

## 📁 專案結構

```
src/
├── app/              # App 層（路由、Provider）
├── pages/            # 頁面元件
├── features/         # 功能元件
├── components/       # 共用元件
│   ├── ui/          # 基礎 UI 元件
│   └── layout/      # 佈局元件
├── stores/           # Zustand stores
├── hooks/            # 自定義 hooks
├── api/              # API 客戶端
├── types/            # TypeScript 類型
└── utils/            # 工具函數
```

---

## 🛠️ 技術棧

- **React 18** - UI 框架
- **TypeScript** - 類型安全
- **Vite** - 建置工具
- **Tailwind CSS** - 樣式框架
- **React Router** - 路由管理
- **Zustand** - 狀態管理
- **React Query** - 伺服器狀態管理
