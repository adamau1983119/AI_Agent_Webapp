# 環境變數配置指南

## 快速配置步驟

### 1. 創建 .env 文件

在 `backend` 目錄下創建 `.env` 文件，並添加以下配置：

```env
# MongoDB 配置
MONGODB_URL=mongodb://localhost:27017
MONGODB_DB_NAME=ai_agent_webapp

# DeepSeek API Key
DEEPSEEK_API_KEY=your_api_key_here

# 其他配置（可選）
ENVIRONMENT=development
AI_SERVICE=deepseek
```

### 2. MongoDB 配置選項

#### 選項 A：本地 MongoDB（推薦用於開發）
```env
MONGODB_URL=mongodb://localhost:27017
```

#### 選項 B：MongoDB Atlas（雲端）
```env
MONGODB_URL=mongodb+srv://<username>:<password>@<cluster>.mongodb.net/?retryWrites=true&w=majority
```

### 3. DeepSeek API Key

從 https://platform.deepseek.com/api_keys 獲取 API Key，然後設置：
```env
DEEPSEEK_API_KEY=sk-your-actual-api-key-here
```

## 測試配置

配置完成後，重啟後端服務器以載入新的環境變數。
