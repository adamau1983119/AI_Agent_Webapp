## 🎯 現在可以開始使用

### 步驟 1：確保後端運行

檢查後端是否在運行：
```powershell
netstat -ano | findstr ":8000"
```

如果沒有運行，啟動後端：
```powershell
cd backend
.\venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 步驟 2：在前端生成主題

1. **訪問前端**: http://localhost:3000
2. **點擊「生成今日主題」按鈕**（紫色按鈕）
3. **等待生成完成**（可能需要幾分鐘）

### 步驟 3：查看生成的主題

生成完成後，您應該看到：
- ✅ 中文標題
- ✅ 30字摘要
