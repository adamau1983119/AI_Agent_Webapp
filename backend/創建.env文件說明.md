# 創建 .env 文件說明

## 📋 步驟

### 1. 在 `backend` 目錄下創建 `.env` 文件

### 2. 複製以下內容到 `.env` 文件

```env
# MongoDB Atlas 配置
MONGODB_URL=mongodb+srv://aadam1983119_db_user:YOUR_PASSWORD_HERE@adamau1983119.yyykp09.mongodb.net/?appName=adamau1983119&retryWrites=true&w=majority
MONGODB_DB_NAME=ai_agent_webapp

# 環境設定
ENVIRONMENT=development
```

### 3. 替換密碼

將 `YOUR_PASSWORD_HERE` 替換為您的實際資料庫用戶密碼。

**⚠️ 重要：如果密碼包含特殊字符，需要 URL 編碼：**
- `@` → `%40`
- `:` → `%3A`
- `/` → `%2F`
- `#` → `%23`
- `?` → `%3F`
- `&` → `%26`
- `%` → `%25`

### 4. 範例

如果您的密碼是 `MyPassword123`，連接字串應該是：
```env
MONGODB_URL=mongodb+srv://aadam1983119_db_user:MyPassword123@adamau1983119.yyykp09.mongodb.net/?appName=adamau1983119&retryWrites=true&w=majority
```

如果您的密碼是 `P@ssw0rd#123`，需要編碼為：
```env
MONGODB_URL=mongodb+srv://aadam1983119_db_user:P%40ssw0rd%23123@adamau1983119.yyykp09.mongodb.net/?appName=adamau1983119&retryWrites=true&w=majority
```

## ✅ 驗證

創建 `.env` 文件後，重啟服務器：

```powershell
cd backend
.\venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

如果看到以下訊息，表示連接成功：
```
✅ 成功連接到 MongoDB: ai_agent_webapp
```

## 🔒 安全提示

- `.env` 文件包含敏感資訊，**不要**提交到 Git
- 確保 `.env` 已在 `.gitignore` 中
- 不要分享您的 `.env` 文件內容
