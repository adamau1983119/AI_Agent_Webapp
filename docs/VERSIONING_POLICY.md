# 版本管理政策（v6 凍結 · v7 演進）

> **建立日期**：2026-06-04  
> **狀態**：生效中  
> **目的**：防止 v6 珍貴文件被誤改或刪除；自本日起**規格與架構 SoT** 以 **v7** 為準。

---

## 1. 原則（必讀）

| # | 規則 |
|---|------|
| 1 | **v6 文件＝唯讀凍結**：僅允許勘誤（錯字、連結失效）且須 PR 標註 `v6-doc-fix-only`；**禁止**改功能描述、路由表、需求範圍。 |
| 2 | **v7 文件＝唯一演進 SoT**：新需求、上架裁剪、AI 成本、架構變更**只寫** v7 系列。 |
| 3 | **程式碼**：repo 內程式為「v6 已實作 + v7 增量」；改碼須對照 `v7.0.0_需求文件.md` 與 `專案完整架構表_v7.md`。 |
| 4 | **Git**：v6 快照已入庫；建議以 tag **`v6.0.0-architecture-freeze`** 還原文件樹；v7 工作請用 **`feature/v7-*`** 分支。 |

---

## 2. v6 凍結清單（禁止刪除 · 禁止覆寫內容）

| 路徑 | 角色 | 處理 |
|------|------|------|
| [`專案完整架構表.md`](../專案完整架構表.md) | v6.0.0 架構 SoT（歷史） | **不得修改**正文；僅能加頂部 3 行「已凍結，請見 v7」橫幅（一次性，由維護者 PR） |

## 4. Git 操作指引

### 4.1 還原 v6 架構表（若被誤改）

```powershell
git checkout v6.0.0-architecture-freeze -- "專案完整架構表.md"
git checkout v6.0.0-architecture-freeze -- "docs/archives/v6.0.0_專案完整架構表_凍結.md"
```

### 4.2 檢查 v6 ref

```powershell
python scripts/check_git_v6_refs.py
```

### 4.3 v7 開發分支

```text
feature/v7-launch-trim
feature/v7-translation-provider
feature/v7-ai-asset-log
```

合併 `main` 前：確認 **未** 修改 `docs/archives/v6.0.0_專案完整架構表_凍結.md` 與 `專案完整架構表.md`（除非為政策允許之凍結橫幅）。
