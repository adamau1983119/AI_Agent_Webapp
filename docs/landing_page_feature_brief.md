# Influencers AI — 首頁／Landing 功能簡介（第三方討論用）

> **用途**：與設計／產品第三方討論「登入前介紹頁」方案  
> **狀態**：現況盤點（非最終文案）  
> **更新**：2026-06-02  
> **產品**：Influencers AI（網紅 AI 助手）  
> **相關**：`專案完整架構表.md`、`docs/publish_post_kit_spec.md`、**[`landing_page_客戶開發需求.md`](./landing_page_客戶開發需求.md)**（**開發需求 SoT**）

---

## 1. 背景與目標

| 項目 | 說明 |
|------|------|
| **現況** | 根路徑 `/` 依登入狀態導向 `/login` 或 `/dashboard`，**無**對外介紹頁 |
| **目標** | 新增「第一頁」：介紹核心功能、說明好處、**引導註冊／登入** |
| **文案原則** | 每項「好處」**≤20 字**（繁中），利於卡片／輪播排版 |
| **MVP 主路** | 站內產出素材 → **複製**到 FB／IG 等發布（**非站內代發**） |

---

## 2. 首頁建議主打（6 項）

對外 Landing 建議只強調下列 6 項；其餘收「進階功能」折疊區。

| # | 功能 | 好處（≤20字） |
|---|------|----------------|
| 1 | 主題趨勢 | 自動收時尚美食熱點，選題省時間 |
| 2 | AI 寫稿／重生 | 一鍵產文配圖，少花構思時間 |
| 3 | 建立頻道（AI 助手） | 用說話建頻道，不必懂 RSS |
| 4 | 靈感策劃 | 搜尋加 AI 對話，找企劃靈感 |
| 5 | 風格學習 | 按讚踩學偏好，越用越像你 |
| 6 | 複製發文（Post Kit） | 標題內文標籤複製，貼平台即發 |

> **備註**：Post Kit 為產品規格主路（L0）；**完整 UI 尚未交付**，對外文案可寫願景並標「即將推出」或弱化，依商務決策。

---

## 3. 登入前功能

| 功能 | 好處（≤20字） |
|------|----------------|
| 語言選擇 | 繁中英日，一開始就懂介面 |
| Google 登入 | 免註冊密碼，幾秒進站 |
| Email 登入／註冊 | 習慣信箱者也能用 |
| 忘記密碼／驗證信 | 帳號可自救，少找客服 |

**路由參考**：`/language`、`/login`、`/register`、`/forgot-password`、`/verify-email`

---

## 4. 登入後 — 主選單（Sidebar）

| 功能 | 路由 | 好處（≤20字） |
|------|------|----------------|
| 儀表板 | `/dashboard` | 今日排程熱門一覽，進站知要做什麼 |
| 主題列表 | `/topics` | 自動收趨勢內容，選題不漏拍 |
| 主題詳情 | `/topics/:id` | 內文配圖重生稿，一頁準備發文 |
| 我的頻道 | `/channels` | 自訂類別地區，最多三條內容線 |
| 建立頻道 | `/channels/create` | AI 助手帶設定，不必懂技術 |
| 靈感策劃 | `/inspiration` | 搜尋加 AI，找企劃靈感 |
| 風格檔 | `/style-profile` | 評分學偏好，語氣越來越貼你 |
| 一鍵發布／發布助手 | `/publish` | 集中發文操作（頁面已有） |
| 平台連線 | `/social-connect` | 連 Facebook 粉專（進階選用） |
| 偏好設定 | `/preferences` | 調類別權重，內容更對味 |
| 排程 | `/schedule` | 看自動收主題時間（營運向） |
| 設定 | `/settings`（Header） | 改姓名語言帳號，與偏好分開 |

---

## 5. 平台能力（介紹頁可寫、不必單獨一頁）

| 能力 | 好處（≤20字） | 備註 |
|------|----------------|------|
| 自動收集（約 6h） | 背景抓 RSS，不用自己刷新聞 | 後端排程 |
| 多語言介面 | 繁中英日，海外網紅也能用 | zh-TW／en／ja |
| 來源驗證 | 推薦來源較可靠，少亂連 | v5.0 |
| Post Kit（L0） | 標題內文標籤複製貼平台發 | 規格見 `publish_post_kit_spec.md` |
| API 代發（L2） | 站內一鍵發文 | **選配／非 MVP** |
| 導師／同伴模式 | 深度企劃對話 | **規劃中，未上線** |

---

## 6. 建議弱化或折疊（Landing 次要）

- 平台連線（Meta OAuth）— 進階、設定門檻高  
- 排程檢視 — 營運／技術向  
- 偏好權重細調 — 進階個人化  
- 發布助手頁 — 若 UI 仍空，避免當主 CTA
