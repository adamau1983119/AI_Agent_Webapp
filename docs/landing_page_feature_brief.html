Influencers AI — 首頁／Landing 功能簡介

第三方討論用 · 更新 2026-06-02 · 對應 docs/landing_page_feature_brief.md

1. 背景與目標

項目說明
現況根路徑 / 導向登入或儀表板，無對外介紹頁
目標新增第一頁：介紹功能、說明好處、引導註冊／登入
文案原則每項好處 ≤20 字（繁中）
MVP 主路站內產素材 → 複製到 FB／IG 發布（非站內代發）

2. 首頁建議主打（6 項）

#功能好處（≤20字）
1主題趨勢自動收時尚美食熱點，選題省時間
2AI 寫稿／重生一鍵產文配圖，少花構思時間
3建立頻道（AI 助手）用說話建頻道，不必懂 RSS
4靈感策劃搜尋加 AI 對話，找企劃靈感
5風格學習按讚踩學偏好，越用越像你
6複製發文（Post Kit）標題內文標籤複製，貼平台即發
Post Kit 為規格主路；完整 UI 尚未交付，對外文案需商務決策。

3. 登入前功能

功能好處（≤20字）
語言選擇繁中英日，一開始就懂介面
Google 登入免註冊密碼，幾秒進站
Email 登入／註冊習慣信箱者也能用
忘記密碼／驗證信帳號可自救，少找客服

4. 登入後 — 主選單

功能路由好處（≤20字）
儀表板/dashboard今日排程熱門一覽，進站知要做什麼
主題列表/topics自動收趨勢內容，選題不漏拍
主題詳情/topics/:id內文配圖重生稿，一頁準備發文
我的頻道/channels自訂類別地區，最多三條內容線
建立頻道/channels/createAI 助手帶設定，不必懂技術
靈感策劃/inspiration搜尋加 AI，找企劃靈感
風格檔/style-profile評分學偏好，語氣越來越貼你
一鍵發布/publish集中發文操作
平台連線/social-connect連 Facebook 粉專（進階）
偏好設定/preferences調類別權重，內容更對味
排程/schedule看自動收主題時間
設定/settings改姓名語言帳號

5. 平台能力（可寫於介紹頁）

能力好處備註
自動收集背景抓 RSS，不用自己刷新聞約 6h
多語言繁中英日，海外網紅也能用—
來源驗證推薦來源較可靠，少亂連v5.0
Post Kit標題內文標籤複製貼平台發L0 規格
導師模式深度企劃對話規劃中

6. 建議弱化或折疊
