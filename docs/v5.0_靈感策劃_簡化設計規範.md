## 2. Token 使用成本分析

### 2.1 現有 Token 使用情況

| 功能 | AI 調用次數 | 平均 Token | 成本估算 |
|------|:----------:|:---------:|:--------:|
| 簡單搜尋 | 0-1 次 | 500-1000 | 低（僅在 Google 結果不足時） |
| 關鍵字提取 | 1 次 | 200-300 | 低 |
| 熱門主題 | 0-1 次 | 500-1000 | 低 |

### 2.2 新功能 Token 使用估算（已更新：根據客戶要求）

| 功能 | AI 調用次數 | 平均 Token | 成本估算 | 客戶要求 |
|------|:----------:|:---------:|:--------|---------|
| **問題生成** | 1 次 | 300-500 | 中 | ✅ 必須：100% AI 動態生成 |
| **來源驗證** | 1 次 | 500-800 | 高 | ✅ 必須：AI 驗證 |
| **內容生成** | 1 次 | 2000-3000 | 高 | ✅ 必須：核心功能 |
| **偏好學習** | 1 次（可選） | 200-300 | 低 | ✅ 必須：AI 學習（僅在學習時） |

**總計（單次完整流程）**：
- **標準流程**：3 次 AI 調用（問題生成 + 來源驗證 + 內容生成）= **2800-4300 Token**
- **包含學習**：4 次 AI 調用（+ 偏好學習）= **3000-4600 Token**
- **最優情況**：2800 Token（簡單主題，快速驗證）
- **最差情況**：4600 Token（複雜主題，完整學習）

### 2.3 成本優化策略（已更新：根據客戶要求）

#### 策略 1：問題生成（客戶要求：100% AI 動態生成）

**客戶要求**：100% AI 動態生成，不使用任何預設模板

**實現方案**：
- ✅ 使用 AI 動態生成問題
- ✅ 每次消耗 300-500 Token
- ✅ 靈活性最高，完全個性化

**成本**：300-500 Token/次（必須）

#### 策略 2：來源驗證（客戶要求：需要 AI 驗證）

**客戶要求**：來源驗證必須使用 AI，不使用邏輯判斷

**實現方案**：
- ✅ 使用 AI 驗證資訊真實性
- ✅ 每次消耗 500-800 Token
- ✅ 更準確的驗證結果

**成本**：500-800 Token/次（必須）

#### 策略 3：偏好學習（客戶要求：需要 AI 學習）

**客戶要求**：偏好學習必須使用 AI，不使用統計方法

**實現方案**：
- ✅ 使用 AI 分析用戶互動模式
- ✅ 每次消耗 200-300 Token
- ✅ 更智能的偏好識別

**成本**：200-300 Token/次（可選，僅在學習時）

#### 策略 4：內容生成優化（節省 500-1000 Token）

**方案 A：優化 Prompt 長度**
- 減少冗餘描述
- 使用結構化 Prompt
- **節省**：約 20-30% Token

**方案 B：快取機制**
- 相同主題的搜尋結果可快取
- **節省**：重複搜尋時零成本

## 3. 簡化架構設計

### 3.1 核心流程（已更新：根據客戶要求）

```
用戶輸入主題
    ↓
檢查用戶偏好（資料庫查詢，零成本）
    ↓
AI 動態生成問題（1 次 AI 調用，必須）
    ↓
用戶回答問題
    ↓
多來源搜尋（Google Custom Search，零 AI 成本）
    ↓
AI 驗證來源（1 次 AI 調用，必須）
    ↓
生成內容（1 次 AI 調用，必須）
    ↓
AI 學習偏好（1 次 AI 調用，可選）
    ↓
輸出結果
```

**Token 使用**：
- **標準流程**：3 次 AI 調用 = **2800-4300 Token**

# backend/app/services/preference_service.py

class PreferenceService:
    """偏好管理服務（簡化版）"""
    
    async def get_preferences(self, user_id: str) -> Dict:
        """取得用戶偏好（資料庫查詢）"""
        pass

互動數據：
{interaction_data}

要求：
1. 識別用戶的輸出格式偏好
2. 識別用戶的語氣風格偏好
3. 識別用戶的地區偏好
4. 識別用戶的主題類型偏好

格式：
輸出格式偏好: [格式名稱]
語氣風格偏好: [風格名稱]
地區偏好: [地區列表]

**3. QuestionGeneratorService（AI 動態生成，必須）**
```python
# backend/app/services/question_generator_service.py

class QuestionGeneratorService:
    """問題生成服務（100% AI 動態生成）"""
    
    async def generate_questions(
        self, 
        topic: str, 
        existing_preferences: Dict = None,
        conversation_history: List[Dict] = None
    ) -> List[Dict[str, Any]]:
        """
        使用 AI 動態生成問題（不使用預設模板）
        
        每次調用消耗 300-500 Token
        """
        ai_service = AIServiceFactory.get_service()
        
        prompt = f"""作為專業的網紅靈感助手，請根據以下主題生成最多 3 個針對性問題，幫助客戶縮小範圍。

主題：{topic}

要求：
1. 問題要精準、有針對性
2. 最多生成 3 個問題
3. 每個問題提供 3-5 個快速選擇選項
4. 問題要能幫助客戶明確需求

格式：
問題1: [問題內容]
選項: [選項1, 選項2, 選項3, ...]

問題2: [問題內容]
選項: [選項1, 選項2, 選項3, ...]
"""
        
        response = await ai_service.generate(prompt)
        # 解析 AI 回應
        return self._parse_questions(response)
```
