DeepSeek 蒸餾成「珍貴資料」

第三方溝通用 · Influencers AI · v7.0.0 · 2026-06-04 · 對應 deepseek_asset_distillation_third_party_brief.md

Influencers AI 只把 DeepSeek 用在「使用者主動要的發文素材」；RSS 標題翻譯改零成本或便宜機器翻譯，且所有 AI 產出一律寫入資料庫快取，避免重複付費。

1. 為什麼要蒸餾

問題說明
成本測試期：少量主題收集卻大量 API（收集時每則標題翻譯 + 排程自動收）
浪費同一內容重翻、無故重新生成 = 丟棄已付費輸出
混淆「看懂標題」不應與「寫可發布短文／腳本」同一套高價 AI

2. 珍貴資料（要留、要版本化）

資產儲存說明
短文 + 腳本contents發文素材；含 model、prompt 版本
版本歷史contents.versions[]重新生成不覆蓋舊稿
卡片譯文快取titles_i18n按鈕翻譯後永久快取，第二次 0 API
收集主標title / original_titleRSS 原文，不被翻譯覆寫
（規劃）日誌ai_generations稽核 topic、種類、是否快取
不燒 DeepSeek：背景每則 RSS 自動改寫標題、無人點開就批量生成全文。

3. 四層策略 L0～L3 + 生成

層行為技術成本
L0收集主題卡，保留來源語言標題無 AI≈0
L1顯示主標；語言不同才顯示翻譯鈕UI≈0
L2使用者按鈕才翻標題／摘要Google／Azure MT（規劃）低
L3社群風格標題改寫（可選）DeepSeek Flash按次
生成詳情短文、腳本、重生DeepSeek Flash（核心）按次·限流

4. MVP 主路

頻道 RSS 收集 (L0)
  → 主題卡 (L1，按需 L2/L3)
  → 詳情「生成內容」(DeepSeek Flash)
  → Post Kit 複製 → FB／IG 發文
