## 四條變現路線（產品敘事對齊）

### 1. Trend Alert（趨勢警報）

| 維度 | 內容 |
|------|------|
| **價值** | 歐美話題在港日尚未爆發前推送；訊息差套利 |
| **MVP 伏筆** | `is_trend_alert: bool`（預設 false） |
| **v7.1 邏輯** | 批次或離線 job 比對增速／跨源重複；達閾值設 `is_trend_alert=true` |
| **UI** | `/discover` 篩選或徽章；付費牆可僅開放 alert 訂閱 |
| **成本** | 優先規則引擎 + Mongo 聚合；**非**每卡 Flash |

### 2. KOL Copilot（網紅共創助手）

| 維度 | 內容 |
|------|------|
| **價值** | 從公共卡一鍵帶入頻道助手／靈感；縮短選題到發文 |
| **MVP** | 公共牆 **只讀**；付費主路仍為 `/channels/create` assist |
| **v7.1 邏輯** | `/discover` 卡 CTA「用此靈感開頻道」→ 預填助手 context（`summary_flash` + 標題） |
| **成本** | 僅在用戶點擊時 Flash；**禁止** feed 載入時觸發 |

### 3. 白皮書／深度包（Premium Digest）

| 維度 | 內容 |
|------|------|
| **價值** | 將多卡 `summary_flash` 聚合成週報／領域包（時尚／美食／時事） |
| **MVP** | 無聚類；單卡 `summary_flash` 已足演示 |
| **v7.1 邏輯** | 排程 Pro **僅**聚合 job（非用戶即時）；輸出 PDF／Post Kit 模板 |
| **成本** | Pro 出口隔離；與公共 8h Flash 分帳 |

### 4. 時空膠囊（Time Capsule）

| 維度 | 內容 |
|------|------|
| **價值** | 保存「當時歐美怎麼報」vs 港日後續演變；內容考古 |
| **MVP 伏筆** | `source_country` + `created_at` 窗（36h 滾動已存在） |
| **v7.1 邏輯** | 歸檔 collection；超窗卡移入 `public_topics_archive` 可查 |
| **UI** | 詳情時間軸；付費解鎖歷史窗 |
