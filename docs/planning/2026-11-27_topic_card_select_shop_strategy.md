## 1. 觀察與假設（使用者提出）

1. Welcome 改版後，客人願意多看主題卡，但少往下看其他卡。  
2. 一直以來甚少客人登入並使用 AI 生成文章／標題圖。  
3. 產品重點＝網紅助理；約 1 分鐘七步可出 IG／FB PO。  
4. 幾乎無人用過「我的頻道」。  
5. **大膽假設**：主題卡內容不夠吸引 → 不想生成文＋標題圖。  
6. 證據：自家 IG 多數 post 僅約 **3～10** 觀看；韓劇／亞洲娛樂相關可到約 **17**；比特幣／財經相關約 **20** → 演算法不推＝標題／內容弱。  
7. 內容才是網紅一切 → 應加強 RSS 主題卡搜尋／入選邏輯。  
8. 先釐清現有三類邏輯：有沒有按「最好／最新 SEO」才產卡？  
9. 定位應像 Joyce／連卡佛：**Select shop**——把最精品卡送到客人面前，有興趣才生成。  
10. 擬新增：**亞洲娛樂**（日／韓／泰明星娛樂）、**環球股市**（日／台／美股票）。  
11. 現有三類擬收窄題材：  
    - 時尚趨勢 → 日本／歐美時尚＋化妝品趨勢  
    - 美食與餐飲 → 健康飲食＋中年健康  
    - 社交趨勢 → AI／政治／科學

## 2. 市場策略可行性結論（一句）

**方向對（內容＝選品，不是再堆 CTA）**；但站內數據目前**更支持**「註冊→第一次 compose 斷點」與「MC 未進漏斗」，**尚未單獨證明**「卡內容不夠好看」是主因。IG 3～10／17／20 可作**選題信號**，樣本太小不可當唯一 KPI。Select shop 要配套**更嚴入選**；單純加頻道會變寬貨架，與精品店張力需先拍板。

## 4. 現行產卡邏輯（問 8 答案）

**沒有**按「最好最新 SEO」產卡。

| 機制 | 現況 |
|------|------|
| 三類 ID | `fashion`／`food`／`trend`（UI：時尚趨勢／美食與餐飲／社交趨勢） |
| 配額 | 每日 04:00 HKT × 各 **5**＝**15**；`generate_content: false` |
| 選源 | [`feed_roles.py`](../../backend/app/config/feed_roles.py) 每類 5 角色 × 1；RSS **源站順序**掃 entry |
| 關卡 | 正文長度、付費牆、圖可壓 JPG（[`topic_publish_gate.py`](../../backend/app/services/automation/topic_publish_gate.py)） |
| 分數 | 時效／來源／完整度／相關有算；**不拿來排序選卡** |
| SEO／搜尋量／SERP | **無** |
| 精品重排／編輯短名單 | **無**（`selection.mode: off`） |
| 「社交趨勢」實際源 | TechCrunch／Verge／WIRED 等＝**科技文化**，非社群熱搜 |

→ 現狀較接近「可信 RSS 里最新且過關的一篇」，**不是** Select shop 精品櫃。

## 5. 各提案可行性

| 提案 | 可行性 | 備註 |
|------|--------|------|
| Select shop 定位 | **高（戰略）** | 須收窄 RSS＋提高入選／可選啟用 enforce 選卡 |
| 三類題材收窄（日歐時尚＋美妝；健康／中年；AI／政治／科學） | **高** | 主要改 feed／角色／關鍵字錨；改動面小於新類 |
| 新增亞洲娛樂 ×5 | **中高（市場）／中（工程）** | IG 信號相對強；需新 Category、feeds、Dashboard／Welcome／i18n／digest 期望值 |
| 新增環球股市 ×5 | **中（市場）／中（工程）** | 比特幣信號可作試點；合規／標題敏感度要注意 |

| 用內容 alone 解轉換 | **不足** | 仍須並看註冊→compose、一鍵出 po、Day14 |
