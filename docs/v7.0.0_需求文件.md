| 現象 | 影響 |
|------|------|
| 單用戶、少量主題收集曾產生 **高額 DeepSeek**（歷史多為 v4-pro + 收集時逐則翻譯） | 無法支撐 100+ 用戶 |

## 2. v7 產品目標（North Star）

**一句話**：網紅以**自己的頻道 RSS** 收集主題 → 主題卡閱讀（方案 C）→ 詳情 **DeepSeek 生成**可發素材 → **Post Kit 複製發文**；其餘能力預設隱藏或標「即將推出」。

### 2.1 成功指標（KPI）

| 指標 | v7 目標（可調） |
|------|-----------------|
| 新用戶首週 DeepSeek 成本 | 較 v6 測試帳戶 **降 ≥ 80%**（收集關 AI 翻譯後） |
| 主題卡翻譯 | **按需**；快取命中 **0** 次 API |
| 同一 topic 無確認不重生成 | API 層可拒絕或需二次確認 |
| 上架功能清單 | 僅 **P0** 路由對外；P1/P2 隱藏或 admin |

## 5. AI 與翻譯策略（核心）

### 5.1 四層模型

```text
L0  收集：RSS 原文 → title / original_title（零 AI）
L1  顯示：方案 C（主標=收集語言；介面語≠收集語 → 按鈕）
L2  按需翻譯：免費／便宜 MT → titles_i18n / description_i18n（永久快取）
L3  深度：DeepSeek Flash 僅在用戶要「社群風格標題」或 L2 不可用時
```

**原則**：主題卡**不必** DeepSeek 翻譯；**必須** DeepSeek 的是使用者明確觸發的**內容生成**。

### 5.2 DeepSeek 保留清單

| 場景 | 模型 | 限流建議 |
|------|------|----------|
| 詳情 `POST …/contents/…/generate` | Flash | 每 topic 每日 N 次 |
| 詳情 `regenerate` | Flash | 需確認 + version |
| 靈感 `assistant/generate` | Flash | 沿用 CostMonitor |
| 頻道 `assist` | Flash | 每 session 上限 |
| 收集標題翻譯 | **關** | env false |
| 卡片 `translate-display` | L2 優先 | 快取後禁止重呼 |

### 5.3 環境變數（v7 正式建議）

```env
DEEPSEEK_MODEL=deepseek-v4-flash
ENABLE_SCHEDULED_TOPIC_COLLECTION=false
ENABLE_AI_TOPIC_TRANSLATION=false
ENABLE_AI_TOPIC_FALLBACK=false
AUTO_START_SCHEDULER=false
# v7 新增（規劃）
TRANSLATION_PROVIDER=none
# TRANSLATION_PROVIDER=google  # 需 GOOGLE_TRANSLATE_API_KEY
```

`ENVIRONMENT=production` 時若仍自動啟動排程，須在 v7 明確改為 **與 cost_controls 一致**（見架構表 v7）。

### 6.1 資料分類

| 資產類型 | 儲存位置 | v7 規則 |
|----------|----------|---------|

### 6.2 產品行為

| 行為 | 需求 |
|------|------|
| 同 topic、同 `prompt_version`、同語言再次 generate | 回傳 409 或「使用現有 vN」 |
| 翻譯按鈕第二次點擊 | 僅讀 DB，無 API |
| 刪除 topic | 軟刪 `status=deleted`；content 保留政策待 R7-09 |

## 12. Discover SKU（大眾免費主題卡 · GTM 需求）

> **架構 SoT**：[`專案完整架構表_v7.md`](../專案完整架構表_v7.md) Discover 章節

### 12.1 客戶需求（摘要）

| 維度 | 需求 |
|------|------|
| **痛點** | 網紅陷入同溫層，缺乏跨文化新選題 |
| **定位** | 跨文化、跨語言靈感破繭器；即時動態牆（Real-time News Feed） |
| **賣點** | 歐美英文即時資訊 → 港日自媒體（訊息差套利） |
| **體驗** | 進站 **原生母語（zh-TW／ja）**；無閃爍、無破碎感；**讀取零 LLM** |
| **MVP 門檻** | **真管線、真 30 批／8h、港日同質**（非 Mock 假牆） |

### 12.2 技術鐵律（與第三方簡報取捨）

| 採用 | **禁止**（PR 失敗條件） |
|------|-------------------------|
| **FastAPI + MongoDB + Redis**（擴充現有流水線） | Node.js 執行期主線、PostgreSQL／SQLAlchemy |
| **RSS + Feed Health 白名單**（MVP） | 住宅 Proxy Pool、Puppeteer／Playwright **必達** |
| **Hybrid 分流**：DeepL 皮（≤20 字）+ Flash `summary_flash` 骨 | 一次多語 JSON 作 **MVP 唯一**路徑（可留 P2 演進） |
| 背景 **8h 批次**；前端 **只讀** `GET .../feed` | feed 內觸發 generate／assist／Pro |

### 12.3 港日同質（驗收定義 · 2026-06-11 鎖定）

| 層級 | MVP 必達 | 備註 |
|------|----------|------|
| **標題（皮）** | 同一卡 **zh-TW + ja** 皆於**批次內** DeepL 預寫入 `topic_translations`（`standard_translation`） | 用戶讀 `/discover` 時 **Network 翻譯 API = 0** |
| **內文（骨）** | 共用 **`summary_flash` 事實精要**；依 `lang` 顯示策略一致 | 日文內文「地道改寫」若超出 DeepL 皮能力 → **v7.1**，不阻 MVP |
| **讀取** | `GET /api/v1/public/topics/feed?lang=zh-TW\|ja` **200**；無外連 DeepSeek／DeepL | 見 **E0-Discover-i18n** 截圖 |

### 12.4 環境分流政策（防 6/6 翻版）

> **命名鐵律**：分流鍵為 **`ENVIRONMENT`**（`development`／`staging`／`production`），**非** `APP_ENV`；落點 [`config_module.py`](../backend/app/config_module.py)。

| 環境 | `ENABLE_PUBLIC_FEED_PIPELINE` | `safe_batch_size` | 8h Cron |
|------|------------------------------|-------------------|---------|
| **development** | **false**（預設） | **一律 2**（含手動 CLI／誤開 pipeline） | **不註冊**（僅腳本觸發） |
| **staging** | 審核後 `true` | **30**（`PUBLIC_FEED_BATCH_SIZE`） | 可開；**須**人工盯後台 |
| **production** | 審核後 `true` | **30** | 8h；**須** DT-5 每日預算告警 |

**已實作（PF-H · `bebf6d0`）**：`settings.safe_batch_size` property；`run_public_feed_batch` 強制上限 + 迴圈 `break`；`scheduler` 於 development **不註冊** `public_feed_batch` cron；`log_cost_event("PUBLIC_FEED_DEV_CAP")`；`GET /health` → `cost_controls.safe_batch_size`／`public_feed_batch_size`。

**營運邊界（文件鎖定 · 程式無法 100% 防）**：staging／prod **手滑開 pipeline + 真跑 30 批**仍可能燒 Token → 依 **DT-5**（DeepSeek 後台每日預算告警）+ 人工紀律；見 Token checklist **雙軌驗收**。

## 14. Alter Ego SKU（數位副本 · Onboarding · 2026-06-17）

> **規格 SoT（待建）**：[`docs/ALTER_EGO_SPEC.md`](./ALTER_EGO_SPEC.md)（**AE-0**）  
> **Checklist**：[`docs/v7_alter_ego_checklist.md`](./v7_alter_ego_checklist.md)  
> **與 v7 主路**：**疊加 onboarding 層**；不取代 RSS → 主題卡 → Post Kit；与 Discover／MyChannel **SKU 隔離**

### 14.1 產品定位（摘要）

| 維度 | 決策 |
|------|------|
| 定位 | 新用戶 **1～3 篇範文** → 結構化 **文字 DNA** → **Soul（Flash）→ Shell（YAML）→ Post Kit** |
| 護城河 MVP | **DNA JSON + exemplar + 週 batch Flash patch**；**不做 fine-tune** |
| LLM | Alter Ego 全路徑 **Flash-only**；**Provider 可替換**（現階段 DeepSeek） |
| 詳情長文 | `generate`／`regenerate` 仍 **v7 D2 Pro**（**分路由**；可讀 compressed DNA） |
| Shell v1 | **FB + Threads + X + Visual Prompt**；**IG v1 不做** |
| 驗收 | 一鍵採用；**禁止 Mock**（README） |

### 14.2 AE 工程鐵律（Hard Rule）

| # | 規則 |
|---|------|
| AE-1 | Alter Ego 管線 **Flash-only**；schema fail → Flash 重试或 UX 重贴 |
| AE-2 | `/api/v1/alter-ego/*` 与 `contents/…/generate|regenerate` **路由隔离** |
| AE-3 | **ContentStyleService** 为风格 context **唯一入口** |
| AE-4 | **dna_status**：`pending` \| `active` \| `skipped` \| `legacy_only` |
| AE-5 | DNA 写入 **snapshot + `current_dna_version_id`**；generate 写 **`generation_meta.dna_version_id`** |
| AE-6 | `get_llm_client(namespace="alter_ego")` **assert Flash-only** |
| AE-7 | 首登 **AE 首体验 + Skip** → MyChannel；KPI：Skip rate |
| AE-8 | 禁止 Mock／模糊驗收 |

### 14.3 ContentStyleService + StyleContext

| route | 行為 |
|-------|------|
| `ae` | 仅 `active` 用 DNA；`skipped`／`pending` 用默认 Soul；**不** fallback legacy `style_profiles` |
| `contents_generate` | `active` → **compressed DNA** + **`dna_version_id`**；`legacy_only` → one-liner；`skipped` → preset／空 |
| `assist` | CreateChannel 贴范文 → 同一 `extract` API |

**version_tag**：任何 DNA 更新 bump `current_dna_version_id` 并写 snapshot；Pro 长文生成时冻结当时 version 入 `generation_meta`，便于「文风不对」归因（数据未生效 vs 模型 vs Shell）。

### 14.4 雙層 LLM 防禦

| 層 | 作法 |
|----|------|
| HTTP | `alter-ego` 独立 router + `AlterEgoBodyGateway`；`contents/generate` 维持 `TokenGatewayMiddleware` |
| Factory | `namespace="alter_ego"` Flash-only；`namespace="v7_generate"` 允许 Pro |
| 灰區 | `contents/generate` **可读** `alter_ego_dna`（经 Service），**必须**走 Pro |

### 14.5 首登动线

- `dna_status=pending` → `/onboarding/alter-ego`（必含 **Skip**）
- Skip → `skipped` → `/my-channel`；Settings 留「建立 Alter Ego」
- 回访已 `active`／`skipped` **不**每次强制 onboarding

### 14.6 資料模型（Mongo · 規劃）

|------------|------|
| `alter_ego_dna` | 当前 DNA、`dna_status`、`current_dna_version_id` |

| `user_feedback_logs` | 採用／👍👎 Diff → 週 batch 输入 |
