### 1.2 核心流程

#### 流程 1：智慧助手模式

```
用戶輸入主題
    ↓
AI 分析主題 → 生成問題（最多 3 個）
    ↓
用戶回答問題
    ↓
檢查用戶偏好 → 應用偏好參數
    ↓
多來源搜尋 → 驗證資訊（至少 2 個來源）
    ↓
生成內容（根據格式選擇）
    ↓
輸出結果（標註驗證狀態）
```

#### 流程 2：快速模式

```
用戶輸入主題
    ↓
使用預設偏好（格式、風格等）
    ↓
多來源搜尋 → 驗證資訊
    ↓
生成內容（使用預設格式）
    ↓
輸出結果
```

### 6.3 驗證邏輯（已更新：三層驗證機制）

```python
async def verify_sources(
    information: str,
    sources: List[Dict[str, Any]]
) -> Dict[str, Any]:
    """
    三層驗證機制
    
    第一層：邏輯判斷（零成本）
    - 檢查來源數量（至少 2 個）
    - 檢查來源類型（官方網站 > 媒體 > 維基百科）
    - 檢查來源 URL 格式
    
    第二層：AI 驗證（500-800 Token）
    - AI 分析資訊真實性
    - AI 評估來源可信度
    - AI 提供驗證理由
    - Fallback：如果 AI 驗證失敗，使用邏輯判斷結果
    
    第三層：交叉比對（零成本）
    - 檢查是否有至少 2 個來源支持相同資訊
    - 計算支持來源數量
    - 計算交叉比對可信度
    
    綜合結果：
    - 計算綜合可信度（加權平均：邏輯 20% + AI 50% + 交叉 30%）
    - 決定最終狀態（verified/partially_verified/unverified）
    """
    # 第一層：邏輯判斷
    logic_result = await _logic_verification(sources)
    
    # 第二層：AI 驗證（含 Fallback）
    try:
        ai_result = await _ai_verification(information, sources)
    except Exception as e:
        logger.warning(f"AI 驗證失敗，使用邏輯判斷: {e}")
        ai_result = logic_result
    
    # 第三層：交叉比對
    cross_check = await _cross_reference(sources, information)
    
    # 綜合結果
    return _combine_results(logic_result, ai_result, cross_check)
```
