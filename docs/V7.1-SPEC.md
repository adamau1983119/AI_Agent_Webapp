## 1. 產品定位

| 維度 | Free Discover | MyChannel（付費核心） |
|------|---------------|------------------------|
| **對象** | 匿名／導流 | **登入用戶**（專屬 RSS／關鍵字） |
| **首屏** | `/discover` 探索區 | **登入預設 Dashboard**（`/my-channel` 或改寫 `/dashboard`） |
| **資料來源** | 公共 8h RSS 批次 | **用戶訂閱頻道** collect 結果 |
| **免費層** | 公共卡全文可讀（規格見 Discover） | **Heading + ≤30 字簡介**（Public View） |
| **付費解鎖** | — | **1 點** → **Source URL + 300 字蒸餾精要** |
| **信任** | 公共來源 | **沒 URL 不出卡**；RSS 空 →「暫無更新」（禁止 AI 補題） |

---

## 2. MC 工程鐵律（Hard Rule · PR 拒絕條件）

| # | 鐵律 | 說明 |
|---|------|------|
| **MC-1** | **沒 URL 不出卡** | 入庫／出卡必須含可驗證 `source_url`（`http://` 或 `https://`） |
| **MC-2** | **登入不燒 Token** | 組裝 feed **僅**讀 Mongo + Redis；**禁止**登入同步 collect／Flash／DeepL |
| **MC-3** | **空 RSS 不瞎編** | MyChannel 路徑 **禁止** Layer3 AI 補題；UI「暫無更新」 |
| **MC-4** | **Redis 隔離** | 專用 `my_channel:feed:{user_id}:{lang}`；**禁止** `public_feed:feed:*` |
| **MC-5** | **先扣點再 LLM** | `DECRBY` 失敗 → **不**呼叫 DeepSeek（v7.1 unlock 不觸發 Pro；v7.2 生成另議） |
| **MC-6** | **禁止 Mock／模糊驗收** | 對齊 README、規則 5；禁止假 topics 充 feed |
| **MC-7** | **組裝限流** | 24h 最多 **3 次**卡片組裝；unlock 須 **idempotency** 防連點 |

## 3. 點數模型（MVP）

| 項目 | 規格 |
|------|------|
| **初始點數** | 新用戶 **5 點**（體驗額度） |
| **解鎖** | **1 點**／次 → 回傳 `source_url` + `digest_300` |
| **金流** | v7.1 **不實作**；管理員 `AddPoints(user_id, amount)` |
| **帳本** | Redis + Mongo ledger（`user_id`, `balance`, `transaction_id`, `action`, `amount`, `topic_id`） |
| **用罄** | 仍可看 **Heading + 30 字**；解鎖 CTA 提示加點 |

## 5. API 契約（已實作 · 2026-06-25）

| 方法 | 路徑 | 說明 |
|------|------|------|
| GET | `/api/v1/my-channel/feed?lang=` | 免費層 cards（**不含** `source_url`） |

## 6. 邊界隔離

| 層 | Public Discover | MyChannel |
|----|-----------------|-----------|
| Redis | `public_feed:feed:{lang}` | `my_channel:feed:{user_id}:{lang}` |
| 批次 | `run_public_feed_batch` | **僅** channel collect 排程 |
| HTTP | `GET /api/v1/public/topics/feed` | `GET /api/v1/my-channel/feed` |
| TokenGateway | 不適用（只讀） | v7.1 unlock **不**走 generate |

**grep 守門**：MC 程式碼 **0** 引用 `public_feed:feed:`；**0** 呼叫 `run_public_feed_batch`。
