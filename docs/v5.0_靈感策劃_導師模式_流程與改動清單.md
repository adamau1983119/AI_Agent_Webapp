## 〇、產品目的（2026-05-22 定稿）

1. 透過 **AI 智慧助手** 與使用者一同參與策劃並給予意見。  
2. 進頁體驗與 **我的頻道／建立頻道** 類似：助手先問「今天想策劃什麼靈感？」。  
3. 提供 **類別快捷鈕**（時尚／美食／科技等），可 **多選** 作為話題方向。  
4. 使用者可輸入 **特別標題**（例：東京十大拉麵店；財經界最時尚的美食在哪裡（香港））。  
5. 確認後由助理 **蒐集資料**（網站、相關文章等）作為靈感候選。  
6. 客戶以 **「使用此靈感」(+)** 選取參考；**至少 2 則、建議 3 則以上** 才可進入下一步。  
7. **對話時間軸** 須顯示已選靈感（按鈕／連結，連結 **另開新分頁**），方便隨時回看。  
8. 助理再問 **輸出形式**：拍片（現階段以 **約 1 分鐘短片** 為主）或 **IG**。  
9. 依選擇產出：**1 分鐘片 → 段落級大綱**；**IG → 每批 3 張**，不滿可再生成，**最多 9 張（3 批）**。  
10. 生成結果：**僅當次預覽 + 複製**，**不寫入** MongoDB 內容庫（本階段）。

### 第一原則：對話框必須有上下文（SoT）

靈感策劃 = **可回溯的策劃工作台**，不是一次性 wizard、也不是搜尋完就跳離頁。

| 能力 | 說明 |
|------|------|
| **完整時間軸** | 開場、類別、搜尋確認、結果、+/- 靈感、形式問答、每批生成結果，皆在同一對話可捲動翻查 |
| **可修改** | 改類別組合、改標題、移除已選靈感、改形式、IG 追加批次等；舊結果 **保留在時間軸**（可灰顯標「已過期」） |
| **狀態摘要** | Sticky 區顯示目前：已選類別、已選靈感數、形式、IG 批次數 |
| **禁止行為** | 搜尋卡片「+」**不得**再導向 `/topics` + `localStorage.pendingInspiration`（舊 #36 MVP 暫行，**產品上廢止**） |

## 一、目標流程（導師／同伴模式 — 完整版）

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 0. 進入 /inspiration → 預設「AI 智慧助手」主舞台（比照 CreateChannel）    │
│    POST /assistant/start（無 topic）→ session_id + opening_message       │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 1. AI 開場：「今天想策劃什麼靈感？」（寫入對話時間軸）                      │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 2. 用家：多選類別鈕（美食+財經+時尚…）+ 可選自由標題（一句話）              │
│    → 不立刻搜尋；訊息寫入 session（user_intent）                          │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 3. AI 複述意圖，問：「要依這些方向搜尋靈感參考嗎？」                        │
│    [開始搜尋]  [先不搜，繼續聊]（兩者皆留在對話紀錄，之後可再搜）             │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 4. 用家確認「開始搜尋」→ 後端蒐集（InspirationService + 深度回覆）        │
│    對話顯示：assistant_results（卡片列表，每張有 +）                      │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 5. 用家點 + 選靈感 → 更新 selected_inspirations + selection_bar（sticky） │
│    連結 target=_blank；時間軸追加「已加入：xxx」                            │
│    繼續：selected >= 2 才 enabled（UI 提示建議 >= 3）                       │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 6. 形式問答（寫入對話）                                                     │
│    · 拍片（約 1 分鐘短片）→ 段落級大綱（0–15s / 15–45s / 45–60s 等）       │
│    · IG → 每批 3 張（標題 tab + 文案）；不滿 → 再生成 3 張，最多 3 批共 9 張 │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 7. 顯示生成結果於對話內；提供複製；不寫 contents 集合                       │
│    可選出口（非自動）：建立主題／發布 — 留待後續迭代                          │
└─────────────────────────────────────────────────────────────────────────┘
```

### 流程狀態機（`session.phase` 建議值）

| phase | 說明 |
|-------|------|
| `opening` | 已顯示開場 |
| `intent` | 已選類別／標題，尚未確認搜尋 |
| `collect` | 搜尋進行中 |
| `pick` | 展示結果，可 +/- 靈感 |
| `format` | 已選 >=2 則，選拍片／IG |
| `generate` | 生成中 |
| `done` | 本輪完成（可「重新策劃」開新 revision） |

## 二、產品決策表（2026-05-22 鎖定）

| 議題 | 決策 |
|------|------|
| **靈感最少數** | **≥2** 才可「繼續」；UI 文案 **建議 ≥3**（不同角度） |
| **靈感上限** | 建議 **≤10**（實作時可調，防濫用） |
| **類別鈕** | **多選** = 話題方向；**不**一選就搜尋 |
| **搜尋時機** | AI 複述意圖後，用家按 **「開始搜尋」** 才觸發；可「先不搜」 |
| **創意目標** | 類別組合 + 自由句 **激發跨界創意**（例：美食+財經+時尚 + 香港在地句） |
| **拍片** | 現階段 **~1 分鐘短片**；大綱 = **章節／時間段落**，不做長片分鏡；長片 **後續** |
| **IG** | 每批 **3 張**；不滿可 **再 3 張**；**最多 3 批 = 9 張**（控成本） |
| **儲存** | **僅當次預覽 + 複製**；不寫 MongoDB `contents`；session 訊息可保留供同 session 翻查 |
| **主題列表跳轉** | **廢止** 按 + 跳 `/topics` 之舊行為 |
| **Session 跨日** | ⏳ 待產品再定（當次 only vs 7/30 天「上次策劃」列表） |

## 三、對話訊息類型（前端渲染 + 後端持久化）

每則 `messages[]` 建議結構：`{ id, type, role, payload, revision, superseded?, created_at }`。

| type | role | payload 要點 |
|------|------|----------------|
| `system_opening` | assistant | `opening_message` |
| `user_intent` | user | `category_tags[]`, `free_text` |
| `assistant_intent_ack` | assistant | 複述 + `actions: [search_now, skip_search]` |
| `user_search_confirm` | user | `confirmed: boolean` |
| `assistant_searching` | assistant | loading |
| `assistant_results` | assistant | `items[]`（title, url, snippet, source） |
| `user_toggle_inspiration` | user | `item_id`, `selected: boolean` |
| `selection_summary` | system | `selected[]`, `count`（可隨 sticky 更新） |
| `user_format_choice` | user | `format: short_video_60s \| ig` |
| `assistant_outline` | assistant | `segments[]` 或 `slides[]`（batch 1） |
| `assistant_ig_batch` | assistant | `batch: 2\|3`, `slides[3]` |
| `user_regenerate_ig` | user | 觸發下一批（檢查 batch≤3） |

### 用家修改時系統行為

| 修改 | 行為 |
|------|------|
| 增刪類別／改標題 | 若已搜尋過 → 標記結果 **可能過期**，提示 **重新搜尋** |
| 增刪已選靈感 | 若已生成 → 提示 **需重新生成**；舊生成留於時間軸（灰顯） |
| 拍片 ↔ IG | 清除該形式生成物，回到 `format` |
| IG 第 2、3 批 | **追加**訊息（Batch 1/2/3 並列），不覆蓋 |

## 四、與現有流程的差異（對照）

| 項目 | 現有設計（2026-05 前） | 導師／同伴模式目標 |
|------|------------------------|-------------------|
| 主舞台 | 搜尋模式與助手模式 **並列**；搜尋「+」跳 `/topics` | **僅助手對話** 主路；搜尋為階段內動作 |
| 誰先開口 | 用家輸入主題 +「開始對話」 | **AI 開場**（今天想策劃什麼靈感？） |
| 類別 | 搜尋頁類別鈕，切換 **trending** | 助手區 **多選** 方向，**確認後**才搜尋 |

| TC-3.6 步驟 4 | 「勾 2 張 → 生成」 | 改為 **對話內 ≥2（建議 ≥3）→ 形式 → 生成** |

## 五、後端改動清單

### 5.1 新增／調整 API

| 端點 | 改動 | 說明 |
|------|------|------|
| `POST /assistant/start` | **調整** | `topic` **選填**；無 topic → `session_id` + `opening_message`，`questions=[]`，`phase=opening` |
| `PATCH /assistant/intent` | **新增** | `session_id`, `category_tags[]`, `free_text`；寫入 session + 追加 `user_intent` 訊息 |
| `POST /assistant/confirm-search` | **新增** | 確認搜尋；組 query（類別 + 自由句）→ 呼叫 `inspiration_service` |
| `POST /assistant/toggle-inspiration` | **新增** | `session_id`, `item`, `selected`；更新 `selected_inspirations` |
| `POST /assistant/confirm-format` | **新增** | `format: short_video_60s \| ig`；檢查 `len(selected)>=2` |
| `POST /assistant/generate` | **調整** | 讀取 session：`selected_inspirations` + `parsed_intent`；分支產出 |
| `POST /assistant/generate-ig-batch` | **新增** | 第 2、3 批 IG；`batch<=3`，每批 3 slides |
| `POST /assistant/mentor-response` | **可併** | 原「一句話意圖」端點；可併入 `confirm-search` + 意圖解析 |

**廢止／勿擴充**：前端 `pendingInspiration` + 導向 `/topics` 不屬本流程。

### 5.2 Session 資料模型（MongoDB `inspiration_sessions` 擴充建議）

```python
# 概念欄位（實作時對齊既有 schema）
{
  "session_id": str,
  "user_id": str,
  "phase": str,  # opening | intent | collect | pick | format | generate | done
  "revision": int,
  "category_tags": List[str],       # 例 ["food", "finance", "fashion"]
  "free_text": Optional[str],
  "selected_inspirations": List[Dict],  # title, url, snippet, source, item_id
  "parsed_intent": {
    "format": Optional[str],          # short_video_60s | ig
    "duration_sec": Optional[int],    # 預設 60
    "ig_batches": int                 # 1..3
  },
  "messages": List[Dict],           # 見第三節 type
  "created_at": datetime,
  "updated_at": datetime,
}
```

### 5.3 回應型別（Pydantic — 擴充）

```python
class MentorSearchResponse(BaseModel):
    session_id: str
    phase: str
    items: List[InspirationItem]  # 搜尋候選
    data_summary: Optional[str] = None
    message_id: str  # 對應 assistant_results

class GenerateOutlineResponse(BaseModel):
    session_id: str
    format: str  # short_video_60s | ig
    # 1 分鐘片
    segments: Optional[List[Dict]] = None  # [{ "time_range", "title", "beats" }]
    # IG 單批 3 張
    slides: Optional[List[Dict]] = None    # [{ "tab_title", "caption", "hashtags?" }]
    batch: int = 1
    can_request_more_ig: bool = False
```

| 檔案 | 職責 |

### 5.5 成本控管

| 操作 | 計費／次數建議 |

## 九、小結

- **流程**：AI 開場 → 多選類別 + 可選標題 → 確認搜尋 → 卡片 + 選靈感（≥2，建議 ≥3）→ 形式（1 分鐘片 / IG 3×3 批）→ **對話內預覽 + 複製**。  
- **核心**：**對話上下文為唯一策劃工作台**；與建立頻道助手模式對齊，但產出為策劃物而非 channel。  
- **廢止**：搜尋模式「+ → `/topics`」與 `pendingInspiration` 主題列表橋接。  
- **儲存**：不寫內容庫；session 訊息供當次（及待定 retention）翻查。
