# 靈感策劃「導師／同伴」模式 — 流程與改動清單

> **對應需求**：用家期望 AI 智能助手作為主導，先問「想做什麼主題？」→ 用家一次回覆意圖 → AI 給予**資料**與**框架**（方向與建議）。  
> **建立日期**：2026-03-13  
> **狀態**：待開發  
> **執行時機**：⏸️ **待 v6 整個 Phase 測試完成後，再與 Phase 測試發現的問題一併修改**（不在此階段實作）。

---

## 一、目標流程（導師模式）

```
┌─────────────────────────────────────────────────────────────────────────┐
│ 1. 用家進入「AI 智慧助手」                                               │
│    → 不需先輸入主題，畫面直接顯示 AI 的開場白                             │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 2. AI 主導開場（第一句由系統顯示）                                        │
│    例：「想做什麼主題？可以告訴我主題、想做的形式（例如 5 分鐘 YouTube、   │
│         IG Reels）或目標。」                                              │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 3. 用家一次回覆意圖（一句話）                                             │
│    例：「上環最辣的食肆，想拍一個 5 分鐘關於食最辣的挑戰 YouTube」         │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 4. 後端處理                                                               │
│    a) 解析意圖：主題、形式、長度、平台（可選：用 AI 從一句話抽取）         │
│    b) 搜尋：依主題做網站搜尋（現有 InspirationService + 深度回覆）         │
│    c) 產出「資料」：整理成摘要 + 來源（給用家參考）                        │
│    d) 產出「框架」：依形式/長度給建議結構（例如 5 分鐘影片大綱）            │
└─────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 5. 前端顯示                                                               │
│    - 資料區塊：搜尋整理後的資訊 + 來源連結                                 │
│    - 框架區塊：建議結構（如：開場 30 秒 → 三家店各 1 分鐘 → 結尾 30 秒）   │
│    - 操作：「生成完整講稿／文章」→ 沿用現有 generate 流程                 │
└─────────────────────────────────────────────────────────────────────────┘
```

---

## 二、與現有流程的差異（對照）

| 項目 | 現有設計 | 導師模式目標 |
|------|----------|--------------|
| 誰先開口 | 用家先輸入主題 + 按「開始對話」 | **AI 先顯示開場問句**（想做什麼主題？） |
| 用家輸入 | 多數只輸入「主題」，再答多題選擇 | **一句話說完意圖**（主題 + 形式 + 長度／平台） |
| 後端第一步 | `assistant/start` 要 topic → 產生多個問題 | `assistant/start` 可無 topic → 只回 session + 開場白；用家回覆後再呼叫新端點 |
| 產出重點 | 直接生成「內容」（講稿／文章） | **先產出「資料」+「框架」**，再可選「生成完整內容」 |

## 三、後端改動清單

### 3.1 新增／調整 API

| 檔案 | 改動類型 | 說明 |
|------|----------|------|
| `backend/app/api/v1/inspiration.py` | **調整** | `POST /assistant/start`：`topic` 改為**選填**。若未傳或空字串，只建立 session、回傳 `session_id` + `opening_message`（開場白），`questions` 為空陣列。 |
| `backend/app/api/v1/inspiration.py` | **新增** | `POST /assistant/mentor-response`：請求體 `session_id`, `user_message`。依 `user_message` 解析意圖 → 搜尋 → 產生「資料」+「框架」；回傳 `MentorResponse`（見下）。 |
| `backend/app/api/v1/inspiration.py` | **不刪** | `POST /assistant/generate`：維持現有「生成內容」流程；可改為接受從 mentor-response 帶來的 `parsed_intent`（或從 session 讀取），減少重複問答。 |

### 3.2 新增回應型別（Pydantic）

**建議新增於 `inspiration.py`：**

```python
class MentorResponse(BaseModel):
    """導師模式：資料 + 框架回應"""
    session_id: str
    # 解析出的意圖（供後續 generate 使用）
    parsed_intent: Dict[str, Any]  # 如 topic, format, duration_min, platform
    # 資料：搜尋整理摘要 + 來源
    data_summary: str
    data_sources: List[Dict[str, Any]]  # [{ "title", "url", "snippet" }]
    # 框架：建議結構（例如影片大綱）
    framework: str
    # 可選：深度回覆（與搜尋結果的 AI 綜述一致）
    depth_response: Optional[str] = None
```

### 3.3 新增服務（建議新檔）

| 檔案 | 職責 |
|------|------|
| `backend/app/services/inspiration_mentor_service.py` | **導師流程**： (1) 從 `user_message` 用 AI 解析意圖（topic, format, duration, platform）；(2) 呼叫現有 `inspiration_service.search_inspiration_with_depth_response` 取得搜尋結果與深度回覆；(3) 用 AI 產出「框架」（依 format/duration 產生建議結構）；(4) 將 `parsed_intent` 寫入 session 或回傳，供後續 `assistant/generate` 使用。 |

### 3.4 既有服務的沿用與小改

| 檔案 | 改動 |
|------|------|
| `inspiration_conversation_service.py` | 若需在 session 存「最後一次意圖」或「user_message」，可新增欄位或擴充 `add_user_message` 的儲存結構。 |
| `inspiration_question_generator_service.py` | 導師模式可**不呼叫**問題生成（當 topic 來自用戶一句話時）；或保留給「需要再追問」時使用。 |
| `inspiration_service.py` | 已具備 `search_inspiration_with_depth_response`，直接給 mentor 服務呼叫。 |
| `inspiration_content_generator_service.py` | `generate_content` 可接受來自 `parsed_intent` 的 format、modules 等，無需改介面，僅呼叫端傳入即可。 |

### 3.5 開場白與多語言

- 開場白文案需支援多語言（zh-TW / en / ja）。
- 建議：在後端由設定或 i18n 回傳 `opening_message`；或前端依語言顯示固定開場句（若後端只回「有開場」旗標）。

## 四、前端改動清單

### 4.1 狀態與流程

| 檔案 | 改動 |
|------|------|
| `frontend/src/pages/Inspiration.tsx` | **AI 助手模式**：進入時若未建立 session，先呼叫 `assistantStart('')`（或帶空 topic）取得 `session_id` + `opening_message`；畫面**先顯示開場白**，再顯示一則輸入框讓用家「回覆一句話」。 |
| `frontend/src/pages/Inspiration.tsx` | 用家送出第一句後，呼叫**新 API** `assistantMentorResponse(sessionId, userMessage)`；收到後顯示「資料」區塊 +「框架」區塊；並儲存 `parsed_intent`（或僅 session 內有即可）。 |
| `frontend/src/pages/Inspiration.tsx` | 在已有「資料+框架」的狀態下，顯示按鈕「生成完整講稿／文章」→ 改為呼叫現有 `assistantGenerate(sessionId, parsedIntent)`，將 parsed_intent 當成 answers 傳入（或後端從 session 讀取）。 |

### 4.2 介面結構（建議）

- **區塊 1**：對話氣泡或卡片 — 顯示 AI 開場白（來自 `opening_message`）。
- **區塊 2**：單行或多行輸入框 — 用家輸入「一句話意圖」→ 送出後呼叫 `assistant/mentor-response`。
- **區塊 3**：標題「資料」— 顯示 `data_summary` + `data_sources` 列表（可點連結）。
- **區塊 4**：標題「框架」— 顯示 `framework` 文字（建議結構）。
- **區塊 5**：按鈕「生成完整講稿」— 觸發現有 generate 流程；若需再選格式，可預填 `parsed_intent.format`。

### 4.3 API 客戶端

| 檔案 | 改動 |
|------|------|
| `frontend/src/api/inspiration.ts` | **assistantStart**：允許傳入空字串 `topic`；型別標明 `topic?: string` 或後端接受省略。 |
| `frontend/src/api/inspiration.ts` | **新增** `assistantMentorResponse(sessionId: string, userMessage: string): Promise<MentorResponse>`，對應 `POST /inspiration/assistant/mentor-response`。 |
| `frontend/src/api/inspiration.ts` | 新增型別 `MentorResponse`（與後端 MentorResponse 對齊）。 |

### 4.4 i18n（建議 key）

| Key | 繁中範例 |
|-----|-----------|
| `inspiration.assistant.opening` | 想做什麼主題？可以告訴我主題、想做的形式（例如 5 分鐘 YouTube、IG Reels）或目標。 |
| `inspiration.assistant.replyPlaceholder` | 例如：上環最辣食肆，想拍 5 分鐘 YouTube 食辣挑戰 |
| `inspiration.assistant.dataTitle` | 資料 |
| `inspiration.assistant.frameworkTitle` | 建議框架 |
| `inspiration.assistant.generateFromFramework` | 依此框架生成完整講稿 |

（en / ja 需同步新增。）

## 六、小結

- **流程**：AI 先問「想做什麼主題？」→ 用家一句話回覆意圖 → 後端解析意圖、搜尋、產出**資料**與**框架** → 前端顯示資料與框架 → 可選「生成完整講稿」走現有 generate。  
- **改動重點**：後端 `assistant/start` 支援無 topic、新增 `assistant/mentor-response` 與 `InspirationMentorService`；前端助手模式改為「開場白 → 一句話輸入 → 資料+框架區塊 → 生成講稿」。

此文件可作為實作與排程依據；實作時可再依現有程式結構微調欄位名稱與 API 路徑。
