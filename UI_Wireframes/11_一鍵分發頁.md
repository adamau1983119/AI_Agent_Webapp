## 🔄 互動行為

| 動作 | 結果 |
|------|------|
| 勾選/取消平台 | 更新發布目標 |
| 點擊圖片 | 選擇/取消選擇 |
| 點擊「預覽各平台效果」| 切換到預覽模式 |
| 點擊「發布」| 開始發布流程 |
| 點擊「查看貼文」| 新分頁開啟社交平台 |
| 點擊「重試發布」| 重新發布失敗的平台 |

---

## 📝 開發備註

```
1. 內容會根據各平台自動最佳化
2. 發布使用佇列系統，處理 Rate Limit
3. 失敗自動重試 3 次（5/15/30 分鐘）
4. 發布記錄儲存到資料庫
5. 支援同時發布到多個平台
```

---

## 🔗 頁面流程

```
一鍵分發頁
    │
    ├─ 選擇平台 → 預覽 → 發布
    │
    ├─ 發布成功 → 查看貼文 / 返回主題
    │
    └─ 發布失敗 → 重試 / 加入佇列
```
