## 🔄 互動行為

| 動作 | 結果 |
|------|------|
| 點擊圖片 | 開啟圖片查看器（可滑動切換） |
| 點擊「查看原文」| 新分頁開啟原文連結 |
| 點擊「生成內容」| 跳轉生成頁（需登入） |
| 點擊「分享」| 顯示分享選單 |
| 點擊「收藏」| 加入收藏（需登入） |
| 點擊標籤 | 搜尋相同標籤的主題 |
| 左右滑動 | 切換到上/下一個主題 |
