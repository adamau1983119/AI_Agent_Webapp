## 🔄 互動行為

| 動作 | 結果 |
|------|------|
| 選擇輸出格式 | 更新預設，下次記住 |
| 點擊「開始生成」| 呼叫 AI API 即時生成 |
| 點擊「複製」| 複製到剪貼簿，顯示 Toast |
| 點擊「編輯」| 進入編輯模式 |
| 點擊「重新生成」| 重新呼叫 AI API |
| 點擊「一鍵分發」| 跳轉分發頁 |
| 點擊「👍/👎」| 記錄評分，更新風格檔案 |

---

## 📝 開發備註

```
1. 生成過程使用 SSE (Server-Sent Events) 顯示進度
2. 生成失敗需要有重試機制
3. 評分回饋用於更新風格學習檔案
4. 每次生成都是獨立的 AI API 呼叫
5. 不儲存生成模板，只儲存生成記錄
6. 輸出格式選擇需要即時影響 AI Prompt
```

## 🔗 頁面流程

```
                    ┌→ 一鍵分發頁 (/distribute)
                    │
內容生成頁 ────────┼→ 編輯模式（同頁）
                    │
                    ├→ 重新生成（同頁）
                    │
                    └→ 返回主題詳情頁
```
