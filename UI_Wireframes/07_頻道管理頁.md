## 🔄 互動行為

| 動作 | 結果 |
|------|------|
| 點擊頻道卡片 | 展開/收合詳情 |
| 點擊「編輯」| 跳轉編輯頻道頁 |
| 點擊「刪除」| 顯示確認對話框 |
| 點擊「建立新頻道」| 跳轉建立頻道頁 |
| 下拉刷新 | 更新頻道狀態 |

---

## 📝 開發備註

```
1. 免費版用戶只能建立 1 個頻道（未來）
2. 頻道狀態需要即時顯示（正常/異常/暫停）
3. 來源數量需要從後端即時獲取
4. 本週主題數從資料庫計算
5. 刪除需要二次確認
```

---

## 🔗 頁面流程

```
                    ┌→ 建立頻道頁 (/channels/create)
                    │
頻道管理頁 ────────┼→ 編輯頻道頁 (/channels/:id/edit)
                    │
                    └→ 刪除確認 → 返回頻道管理頁
```
