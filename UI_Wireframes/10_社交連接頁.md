## 🔄 互動行為

| 動作 | 結果 |
|------|------|
| 點擊「連接帳號」| 跳轉到 OAuth 授權頁 |
| OAuth 成功 | 返回應用，顯示已連接 |
| 點擊「取消連接」| 顯示確認對話框 |
| 確認取消 | 移除連接，按鈕變回「連接帳號」|

---

## ⚠️ 錯誤處理

```
1. OAuth 授權失敗
   ┌─────────────────────────────────┐
   │ ⚠️ 連接失敗                     │
   │    請重試或稍後再試             │
   │    [重試]                       │
   └─────────────────────────────────┘

2. Token 過期
   ┌─────────────────────────────────┐
   │ ⚠️ Instagram 連接已過期        │
   │    請重新連接                   │
   │    [重新連接]                   │
   └─────────────────────────────────┘
```

---

## 📝 開發備註

```
1. OAuth 使用 Popup 視窗避免離開應用
2. Token 需要加密儲存
3. Token 自動刷新機制
4. Twitter 初期可設為 Feature Flag 關閉
5. 連接狀態需要即時顯示
```

---

## 🔗 頁面流程

```
社交連接頁
    │
    ├─ 連接帳號 → OAuth 授權 → 成功/失敗
    │
    └─ 取消連接 → 確認 → 移除連接
```
