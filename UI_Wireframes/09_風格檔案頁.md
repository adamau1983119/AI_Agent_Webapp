## 🔄 互動行為

| 動作 | 結果 |
|------|------|
| 點擊預設風格 | 選中並儲存 |
| 點擊「重置風格檔案」| 顯示確認對話框 |
| 確認重置 | 清空所有學習記錄 |
| 下拉刷新 | 更新學習狀態 |

---

## 📝 開發備註

```
1. 學習狀態三階段：冷啟動(0-20)、學習中(20-100)、成熟(100+)
2. 預設風格影響 AI Prompt 的基礎參數
3. 學習偏好從評分記錄分析得出
4. 重置後回到冷啟動階段
5. 成熟階段的風格標籤由 AI 分析生成
```

---

## 🔗 頁面流程

```
風格檔案頁
    │
    ├─ 冷啟動：選擇預設風格
    │
    ├─ 學習中：查看學習進度
    │
    └─ 成熟：查看專屬風格 → 可重置
```
