## 🔄 互動行為

| 動作 | 結果 |
|------|------|
| 輸入主題並搜尋 | AI 提取關鍵字 → 搜尋相關內容 |
| 勾選靈感 | 加入選擇列表（最多 3 個） |
| 點擊「查看原文」| 新分頁開啟原文 |
| 點擊「重新搜尋」| 清空結果，重新輸入 |
| 點擊「根據靈感生成文章」| 跳轉生成頁，帶入選擇的靈感 |

---

## ⚠️ 錯誤處理

```
1. 搜尋無結果
   ┌─────────────────────────────────┐
   │ 😕 找不到相關靈感               │
   │                                 │
   │ 試試看：                        │
   │ • 使用更通用的關鍵字            │
   │ • 簡化你的描述                  │
   │ • 嘗試不同的主題                │
   │                                 │
   │ [重新搜尋]                      │
   └─────────────────────────────────┘

2. 搜尋失敗
   ┌─────────────────────────────────┐
   │ ⚠️ 搜尋失敗，請稍後再試         │
   │ [重試]                          │
   └─────────────────────────────────┘
```

## 📝 開發備註

```
1. AI 使用 DeepSeek 提取關鍵字
2. 搜尋來源：Google Custom Search + 已收集 RSS
3. 固定返回 5 個結果
4. 選擇的靈感會傳到生成頁作為參考
5. 搜尋記錄儲存到資料庫（可選）
```

## 🔗 頁面流程

```
靈感策劃頁
    │
    ├─ 輸入主題 → 搜尋 → 顯示結果
    │
    ├─ 選擇靈感（1-3 個）
    │
    └─ 生成文章 → 內容生成頁（帶入靈感）
```
