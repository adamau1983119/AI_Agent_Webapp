# UI 設計規範

> **專案名稱**：Influencers AI Agents  
> **設計風格**：Lane Crawford 高端時尚電商風格  
> **設計原則**：Mobile First（手機優先）

---

## 📱 設計原則

### Mobile First 策略

```
設計順序：
1️⃣ 手機版（375px）  ← 優先設計
2️⃣ 平板版（768px）  ← 擴展調整
3️⃣ 桌面版（1280px） ← 最後優化
```

### 螢幕斷點

| 裝置 | 寬度 | 說明 |
|------|:----:|------|
| 📱 手機 | 375px | **主要設計目標** |
| 📱 手機 L | 414px | iPhone Plus 系列 |
| 📲 平板 | 768px | iPad 直向 |
| 💻 桌面 | 1280px | 標準桌面 |

## 🎨 Lane Crawford 風格規範

### 配色

```
主色調：
┌─────────────────────────────────────┐
│  ⬛ 黑色 #000000  - 主要按鈕、標題   │
│  ⬜ 白色 #FFFFFF  - 背景、按鈕文字   │
│  🔲 灰色 #666666  - 次要文字         │
│  ▫️ 淺灰 #F5F5F5  - 分隔線、背景     │
└─────────────────────────────────────┘
```

### 字體

```
標題：襯線字體（Serif）
├── 英文：Playfair Display / Georgia
└── 中文：思源宋體 / 明體

內文：無襯線字體（Sans-serif）
├── 英文：Helvetica Neue / Arial
└── 中文：思源黑體 / 蘋方
```

### 按鈕樣式

```
主要按鈕：
┌─────────────────────────────┐
│         登入 LOGIN          │  ← 黑底白字
└─────────────────────────────┘

次要按鈕：
┌─────────────────────────────┐
│         註冊 REGISTER       │  ← 白底黑框
└─────────────────────────────┘
```

### 輸入框樣式

```
底線樣式（Underline Style）：

Email
adam@example.com
─────────────────────────────

密碼
••••••••
─────────────────────────────
```
