## 🔄 互動行為

| 動作 | 結果 |
|------|------|
| 滾動到底部 | 自動載入下一批（20 筆） |
| 點擊分類 Tab | 篩選該分類主題 |
| 點擊「我的頻道」| 展開下拉選擇頻道 |
| 點擊日期篩選 | 展開日期選擇器 |
| 點擊主題卡片 | 跳轉主題詳情頁 |
| 點擊「生成」| 跳轉生成頁（需登入） |
| 左右滑動圖片 | 切換圖片輪播 |

## 📝 開發備註

```
1. 無限滾動：距離底部 200px 時觸發載入
2. 每次載入 20 筆
3. 時間分隔：今天/昨天/本週/更早
4. 圖片使用懶加載（Lazy Loading）
5. 支援下拉刷新（手機版）
6. 快取最近瀏覽的主題
7. 分類 Tab 需要有「粘性」效果（Sticky）
```
