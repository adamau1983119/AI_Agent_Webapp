## 🔄 互動行為

| 動作 | 結果 |
|------|------|
| 修改顯示名稱 | 即時儲存 |
| 切換語言 | 即時生效，UI 更新 |
| 點擊「修改密碼」| 跳轉修改密碼頁 |
| 點擊「已連接帳號」| 跳轉社交連接頁 |
| 點擊「我的頻道」| 跳轉頻道管理頁 |
| 點擊「風格檔案」| 跳轉風格檔案頁 |
| 點擊「登出」| 顯示確認對話框 |

---

## 📝 開發備註

```
1. 語言切換需要即時更新所有 UI
2. 修改密碼需要驗證目前密碼
3. Email 不可修改（作為帳號識別）
4. 登出需要清除 Token 和本地快取
5. 頭像上傳功能可在未來版本加入
```

---

## 🔗 頁面流程

```
個人設定頁
    │
    ├─ 修改密碼頁
    │
    ├─ 社交連接頁 (/social)
    │
    ├─ 頻道管理頁 (/channels)
    │
    ├─ 風格檔案頁 (/style)
    │
    └─ 登出 → 登入頁
```
