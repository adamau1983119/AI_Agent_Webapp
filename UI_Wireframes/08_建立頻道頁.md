## 🔄 互動行為

| 動作 | 結果 |
|------|------|
| 點擊類別卡片 | 選中並進入 Step 2 |
| 點擊地區卡片 | 選中並進入 Step 3 |
| 點擊「上一步」| 返回上一步驟 |
| 點擊「建立頻道」| 建立並顯示成功頁 |
| 自定義關鍵字輸入 | 即時驗證（不可為空） |

---

## ⚠️ 錯誤處理

```
1. 頻道數已滿
   ┌─────────────────────────────────┐
   │ ⚠️ 你已達到頻道上限（3 個）     │
   │    請先刪除現有頻道             │
   └─────────────────────────────────┘

2. 自定義關鍵字過短
   自定義關鍵字
   ab
   ─────────────────────────────────
   ⚠️ 關鍵字至少需要 2 個字元

3. 建立失敗
   ┌─────────────────────────────────┐
   │ ⚠️ 頻道建立失敗，請稍後再試     │
   │    [重試]                       │
   └─────────────────────────────────┘
```

---

## 📝 開發備註

```
1. 類別「其他」需要顯示關鍵字輸入框
2. 地區選擇影響 RSS 來源配置
3. 頻道名稱可自定義，預設為「{地區}{類別}」
4. 自定義關鍵字用於 Google Custom Search 找 RSS
5. 三層備用機制確保頻道永不空白
```

---

## 🔗 頁面流程

```
建立頻道頁
    │
    ├─ Step 1: 選擇類別
    │     ↓
    ├─ Step 2: 選擇地區（+ 自定義關鍵字）
    │     ↓
    ├─ Step 3: 確認設定
    │     ↓
    └─ 成功頁 → 頻道管理頁 / 主題列表頁
```
