## 🎨 設計說明

### 視覺元素

| 元素 | 說明 |
|------|------|
| **Logo** | 品牌標誌，居中顯示 |
| **標題** | 「Influencers AI Agents」使用襯線字體 |
| **語言按鈕** | 大尺寸卡片式按鈕，易於點擊 |
| **版權資訊** | 頁面底部，小字灰色 |

### 互動行為

| 動作 | 結果 |
|------|------|
| 點擊語言按鈕 | 儲存語言偏好 → 跳轉到 `/login` |
| Hover（桌面版）| 按鈕背景變深灰 |

### 響應式調整

| 螢幕 | 調整 |
|------|------|
| 手機 | 語言按鈕垂直排列，全寬 |
| 平板/桌面 | 語言按鈕水平排列 |

---

## 📝 開發備註

```
1. 語言選擇儲存到 localStorage（訪客）或資料庫（會員）
2. 已登入用戶直接跳過此頁，進入主題列表
3. 語言按鈕需要有清晰的視覺回饋
4. 背景可考慮加入微妙的漸層或圖案
```

---

## 🔗 頁面流程

```
語言選擇頁 → 登入頁 → 主題列表頁
     │
     └→ 設定語言後自動跳轉
```
