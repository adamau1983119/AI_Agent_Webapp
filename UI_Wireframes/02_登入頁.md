## 🎨 設計說明

### 視覺元素

| 元素 | 手機版 | 桌面版 |
|------|--------|--------|
| **左側圖片** | 無 | 有，品牌形象圖 |
| **表單區域** | 全寬 | 右側 50% |
| **輸入框** | 底線樣式 | 底線樣式 |

### 輸入框狀態

```
預設狀態：
Email
─────────────────────────  ← 灰色底線

Focus 狀態：
Email
─────────────────────────  ← 黑色底線，加粗

錯誤狀態：
Email
adam@invalid              ← 紅色文字
─────────────────────────  ← 紅色底線
請輸入有效的 Email 地址
```

### 按鈕狀態

```
登入按鈕：
┌─────────────────────────┐
│      登入 LOGIN         │  ← 預設：黑底白字
└─────────────────────────┘

┌─────────────────────────┐
│      登入 LOGIN         │  ← Hover：深灰底
└─────────────────────────┘

┌─────────────────────────┐
│      ◌ 登入中...        │  ← Loading：顯示 Spinner
└─────────────────────────┘

┌─────────────────────────┐
│      登入 LOGIN         │  ← Disabled：淺灰底
└─────────────────────────┘
```

## 🔄 互動行為

| 動作 | 結果 |
|------|------|
| 點擊「登入」| 驗證 → 成功跳轉 `/topics` |
| 點擊「Google 登入」| OAuth 流程 → 成功跳轉 `/topics` |
| 點擊「訪客瀏覽」| 跳轉 `/topics`（有限功能） |
| 點擊「忘記密碼？」| 跳轉 `/forgot-password` |
| 點擊「立即註冊」| 跳轉 `/register` |
| 點擊「🌐 繁中」| 顯示語言切換選單 |
