## 🔄 互動行為

| 動作 | 結果 |
|------|------|
| 點擊「註冊」| 驗證 → 發送驗證郵件 → 跳轉確認頁 |
| 點擊「Google 註冊」| OAuth 流程 → 成功跳轉 `/topics` |
| 點擊「立即登入」| 跳轉 `/login` |
| 點擊「👁️」| 切換密碼顯示/隱藏 |

## ⚠️ 錯誤訊息

```
1. Email 已被使用
   ┌─────────────────────────────────┐
   │ ⚠️ 此 Email 已被註冊            │
   │    使用此 Email 登入 →          │
   └─────────────────────────────────┘

2. 密碼不符合規則
   密碼 Password
   abc123@@
   ───────────────────────────────
   ✗ 8 位字元                 ← 紅色
   ✗ 至少 1 個大寫字母        ← 紅色
   ✗ 僅限英文字母和數字       ← 紅色（有特殊字元）

3. 確認密碼不符
   確認密碼 Confirm Password
   ───────────────────────────────
   ⚠️ 兩次輸入的密碼不相同

4. 名額已滿
   ┌─────────────────────────────────┐
   │ ⚠️ 測試版名額已滿（100/100）    │
   │    請稍後再試或加入等候名單     │
   └─────────────────────────────────┘
```

## 📝 開發備註

```
1. 密碼規則即時驗證，使用 regex: ^(?=.*[A-Z])[A-Za-z0-9]{8}$
2. Email 需要即時檢查是否已存在
3. Google 註冊自動通過驗證，不需發送驗證郵件
4. 100 人限制需要在註冊前檢查
5. 顯示名稱不可為空，最長 50 字元
```
